Q4: "What happens if I work without a permit?"
NAVIGATION PATH:
→ START: Penalties section (Article 81)
→ FIND: Stop-work orders, fines, disconnection possible
→ ENFORCEMENT: Chief Electrical Inspector authority
→ DETAILS: practical-permit-process-LA-ENHANCED.txt (enforcement)
→ QUICK ANSWER: Stop orders + fines + potential service disconnection

ENFORCEMENT CONSEQUENCES:
IMMEDIATE:
• Stop-work order issued
• No further work allowed until permit obtained
• Inspector may red-tag job site

FINES:
• First violation: Warning or fine ($100-500 typical)
• Repeated violations: Escalating fines ($500-2,000+)
• Unsafe work: Higher fines + immediate action

ADDITIONAL PENALTIES:
• Service disconnection (if safety hazard)
• Required removal of work for inspection
• May need to open walls to inspect hidden work
• Insurance may deny coverage (unpermitted work)
• Contractor license at risk (if applicable)
• Difficult property sale (unpermitted work disclosed)

RESOLUTION PROCESS:
1. Stop all work immediately
2. Apply for permit retroactively
3. Pay permit fees + penalties
4. Pass inspections (may require opening walls)
5. Receive sign-off

Q5: "How long is my permit valid?"
NAVIGATION PATH:
→ START: Permit Validity → Section 82-2 [web:82]
→ FIND: 12 months to start work + extension options
→ SUSPENSION LIMIT: 180 consecutive days maximum
→ EXTENSIONS: Up to 180 days each (2 total possible)
→ DETAILS: practical-permit-process-LA-ENHANCED.txt (timeline planning)
→ QUICK ANSWER: 12 months to start, extensions available

PERMIT VALIDITY RULES:
VALIDITY PERIOD:
• 12 months from permit issue date to START work (not 6 months!)
• Mark calendar: [Issue date] + 12 months = Expiration

WORK SUSPENSION LIMITS:
• Cannot suspend work >180 consecutive days
• If suspended >180 days: Permit expires
• Solution: Keep some activity going (even minimal)

EXTENSIONS:
• First extension: 180 days (25% of permit fee)
• Second extension: 180 days (25% of permit fee again)
• Total possible: 1 year + 360 days = 2.3 years maximum
• Request BEFORE expiration (not after)
• Grounds: "Circumstances beyond permittee's control"

EXPIRATION CONSEQUENCES:
• Permit expires = All work stops
• Must apply for NEW permit
• Pay NEW permit fees
• Prior inspections may not transfer
• Solution: Request extension before expiration

Q6: "When do I need rough-in inspection?"
NAVIGATION PATH:
→ START: Inspection Requirements → Rough-in (Article 81)
→ FIND: Before drywall/concealment (mandatory)
→ TIMING: When wiring complete but BEFORE covering
→ PRE-INSPECTION PREP: File 4 has complete checklist
→ SCHEDULING: EPIC-LA only (epicla.lacounty.gov)
→ QUICK ANSWER: BEFORE drywall - inspector must see wiring

ROUGH-IN INSPECTION REQUIREMENTS:
TIMING:
• After: All wiring run, boxes installed, connections made
• Before: Drywall, plaster, stucco, or any covering applied
• Critical: Inspector MUST see all wiring and boxes

WHAT INSPECTOR CHECKS:
• Wiring properly run and supported
• Boxes at correct heights and locations
• Grounding/bonding adequate
• Service entrance proper
• Panel installation correct
• No code violations visible

SCHEDULING (EPIC-LA):
• Log into epicla.lacounty.gov
• Select permit → Request Rough-In Inspection
• Choose available date/time
• Wait: 1-4 weeks depending on season (File 4 has timing)

PRE-INSPECTION CHECKLIST (File 4):
☑️ All wiring visible (not covered)
☑️ Boxes properly installed
☑️ Grounding verified
☑️ Panel accessible and labeled
☑️ Site clean and professional
☑️ Permit displayed at entrance

COMMON MISTAKES:
❌ Drywall crew covers work before inspection → Must open walls
❌ Not scheduling until drywall crew arrives → Delays project
✅ Schedule rough-in IMMEDIATELY when wiring complete

Q7: "What if my inspection fails?"
NAVIGATION PATH:
→ START: Inspection Requirements → Reinspection
→ FIND: Correction list emailed via EPIC-LA
→ PROCESS: Fix violations → Request re-inspection
→ DETAILS: practical-permit-process-LA-ENHANCED.txt (failure handling)
→ QUICK ANSWER: Fix violations, request re-inspection (usually no fee)

INSPECTION FAILURE PROCESS:
NOTIFICATION:
• Inspector emails correction list via EPIC-LA (within 24 hours)
• Each violation listed with:
  - Violation description
  - Code section cited
  - Location in property
  - Correction method required

COMMON ROUGH-IN FAILURES:
• Wiring not properly supported (most common)
• Box heights incorrect (second most common)
• Grounding inadequate
• Panel labeling unclear
• Connections not secured

COMMON FINAL FAILURES:
• GFCI not functioning (MOST COMMON - 35% of failures)
• Panel not labeled
• Loose connections
• Fixtures not properly grounded
• Missing covers/plates

CORRECTION PROCESS:
1. Read violation list carefully
2. Fix all violations (don't skip any)
3. Test corrections (especially GFCI)
4. Request re-inspection via EPIC-LA
5. Wait: 1-4 weeks for re-inspection
6. Pass or repeat process

RE-INSPECTION:
• Usually NO additional fee
• Same inspector typically returns
• Focuses on previous violations
• May find new issues if looking closer

PREVENTION (File 4):
Use pre-inspection checklists:
✅ GFCI Testing Checklist (File 4, Part 3)

✅ Panel Labeling Standards (File 4, Part 3)

Q8: "Can I do alterations without permit?"
NAVIGATION PATH:
→ START: Section 82-3 (Exemptions) → Check 9 categories
→ ANSWER: NO - alterations almost always need permit
→ EXCEPTIONS: Minor repairs only (outlet replacement same type)
→ FEE CALCULATION: File 3 - Per-circuit/outlet fees [web:68]
→ MUST CALL: LA County for exact fee (varies by scope)
→ QUICK ANSWER: Alterations need permit - call LA County for fee quote

ALTERATION PERMIT REQUIREMENTS:
ALWAYS NEED PERMIT:
• Adding new circuits
• Adding new outlets/switches
• Kitchen remodel electrical
• Bathroom remodel electrical
• Service upgrades (100A → 200A)
• Garage conversions
• Room additions
• HVAC electrical
• Water heater replacement (if circuit changed)

SOMETIMES EXEMPT:
• Outlet replacement (same type, same location) - EXEMPT
• Switch replacement (same type, same location) - EXEMPT
• Light fixture replacement (same wiring) - EXEMPT
• Breaker replacement (same type, same rating) - EXEMPT

FEE STRUCTURE (Complex):
• Base: $37.33 [web:68]
• Per-circuit: $23.44 (first 10), $52.68 additional [web:68]
• Per-outlet: $52.68 each [web:68]
• Varies widely by scope

MUST CALL LA COUNTY:
DO NOT GUESS alteration fees
Call: (626) 458-3180
Provide: Exact scope (circuits, outlets, locations)
Get: Written quote with date
Use: Quote in bid to customer
