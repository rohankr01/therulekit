PRACTICAL GUIDE: Outdoor Electrical Installation
================================================================================

STEP-BY-STEP OUTDOOR CIRCUIT INSTALLATION:

PHASE 1: PLANNING & DESIGN

1. Determine Outlet Locations
   Code-required outdoor receptacles:
   □ Front of house: Minimum 1 receptacle (ground level)
   □ Back of house: Minimum 1 receptacle (ground level)
   □ Ground level: Within 6.5 feet of grade
   □ All must be GFCI protected
   
   Recommended additional outlets:
   - Each side of house (left, right)
   - Patio/deck areas (multiple outlets)
   - Near outdoor kitchen/grill area
   - Garage/carport exterior
   - Pool/spa equipment area (special requirements)
   - Garden/landscape areas

2. Plan Lighting Locations
   Outdoor lighting considerations:
   - Building-mounted: Front door, garage, sides
   - Post lights: Driveway, walkway
   - Landscape lighting: Garden beds, trees
   - Security lighting: Motion sensors, floodlights
   - Patio/deck: Overhead, string lights
   
   Lighting types:
   - Line voltage (120V): Requires conduit, permit
   - Low voltage (12V/24V): Transformer needed, usually no permit

3. Choose Weatherproof Equipment
   Receptacles:
   - GFCI required (all outdoor)
   - Weatherproof cover: In-use type (horizontal or vertical)
   - WR (weather-resistant) receptacles required
   - 15A or 20A rating
   
   Boxes:
   - Weatherproof rated (raintight when closed)
   - Metal or non-metallic (PVC common outdoors)
   - Proper gaskets
   - Extension rings for thick siding
   
   Covers:
   - In-use covers: Stay closed with plug inserted
   - Vertical or horizontal orientation
   - Clear lid (see what's plugged in)
   - UL listed for wet locations

4. Plan Underground Wiring Routes
   Underground wiring methods:
   
   Method 1: UF Cable (Direct Burial)
   - Use UF-B (underground feeder) cable
   - Burial depth: 24" minimum (no conduit)
   - Or 18" with 2" of concrete on top
   - Or 12" if protected by GFCI breaker
   - Most common for residential
   
   Method 2: THWN in PVC Conduit
   - Individual THWN wires in Schedule 40 PVC
   - Burial depth: 18" minimum for rigid PVC
   - More expensive but easier to replace wires
   - Required for line voltage landscape lighting
   
   Method 3: Rigid Metal Conduit (RMC)
   - Burial depth: 6" minimum
   - Most expensive
   - Best protection
   - Rarely used residentially

5. Determine Wire Sizing
   20A outdoor receptacle circuits: 12 AWG copper (UF or THWN)
   15A outdoor lighting circuits: 14 AWG copper (UF or THWN)
   
   Voltage drop considerations:
   - Long runs (>100 feet): Upsize wire one gauge
   - Example: 150 foot run, 20A circuit → Use 10 AWG instead of 12 AWG
   - Keeps voltage drop <3%

6. Check Panel Capacity
   Count available breaker slots:
   - Need 2-5 slots for outdoor circuits
   - If insufficient: Consider sub-panel
   
   Load calculation:
   - Outdoor receptacles: 1,800W per 20A circuit
   - Outdoor lighting: 1,440W per 15A circuit
   - Total must not exceed service capacity

PHASE 2: PERMIT APPLICATION

1. Determine if Permit Needed
   Permit REQUIRED for:
   ✓ New outdoor circuits
   ✓ Relocating outdoor outlets
   ✓ Line voltage landscape lighting (120V)
   ✓ Underground feeder to detached structure
   ✓ Outdoor sub-panel installation
   
   Permit NOT REQUIRED for:
   ✗ Replacing outdoor outlets same location (Section 82-3(a))
   ✗ Replacing outdoor light fixtures same location
   ✗ Low voltage landscape lighting (12V/24V)
   ✗ Plugging in equipment to existing outlets

2. Apply via EPIC-LA
   URL: epicla.lacounty.gov
   Permit type: "Electrical Permit - Outdoor Circuits"
   
   Application details:
   □ Number of new circuits
   □ Outlet locations (sketch helpful)
   □ Lighting circuits
   □ Underground wiring routes
   □ Burial depths
   □ Work description
   □ Contractor license # (C-10 required)

3. Pay Permit Fee
   Fee structure:
   - Base: $36.00
   - Per circuit: ~$25-50 each (estimate)
   - Typical outdoor project (2-3 circuits): $100-200
   - Detached structure feeder: Add $100-200
   - Verify current: (626) 458-3180

4. Wait for Approval
   Timeline:
   - Simple outdoor circuits: 5-7 days
   - Detached structure: 10-15 days
   - Complex underground: 10-15 days

PHASE 3: INSTALLATION (Licensed Electrician)

Outdoor Receptacle Installation:

Above-Ground Installation (on building):
□ Cut hole in exterior wall (locate studs)
□ Install weatherproof box (single or double gang)
□ Run wire from panel to box (through walls/attic)
□ Install GFCI receptacle (test button must face up typically)
□ Use WR (weather-resistant) receptacle
□ Proper grounding to box
□ Install weatherproof in-use cover
□ Caulk around box perimeter (seal against water)
□ Label circuit in panel

Below-Ground Installation (underground feed):
□ Trench from panel location to outlet location
□ Proper burial depth (24" for UF, 18" for PVC conduit)
□ Install UF cable or PVC conduit with THWN wires
□ Riser protection: Use conduit from ground to box (min 8" below, 6' above)
□ Install weatherproof box on post or building
□ Connect to GFCI receptacle
□ Backfill trench carefully (avoid damaging wire)
□ Mark underground route (for future reference)

GFCI Installation for Outdoor Circuits:

Option 1: GFCI Receptacle at First Outlet
  → Install GFCI as first outdoor outlet
  → Wire additional outlets to LOAD terminals
  → All downstream outlets protected
  → Cost: $20-40 per GFCI outlet (WR type)
  → Advantage: Easy to identify where GFCI is

Option 2: GFCI Breaker at Panel (RECOMMENDED)
  → Install GFCI breaker at panel
  → Entire outdoor circuit protected
  → All outlets downstream protected
  → Cost: $40-80 per GFCI breaker
  → Advantage: Single protection point, all outlets protected
  → RECOMMENDED for outdoor circuits

Outdoor Lighting Installation:

Building-Mounted Fixtures:
□ Install weatherproof box at fixture location
□ Run wire from switch location to fixture
□ Install exterior-rated light fixture
□ Proper gasket between fixture and wall
□ Caulk around edges (prevent water intrusion)
□ Switch typically inside building
□ Consider timer or photocell control

Line Voltage Landscape Lighting (120V):
□ Trench for underground conduit
□ Install PVC conduit (Schedule 40)
□ Burial depth: 18" minimum
□ Run THWN wires in conduit
□ Install weatherproof boxes at fixture locations
□ GFCI protection required
□ Direct burial fixtures or post lights
□ Connect to GFCI-protected circuit

Low Voltage Landscape Lighting (12V/24V):
□ Install transformer (usually no permit needed)
□ Transformer plugs into GFCI outlet
□ Run low voltage cable (direct burial rated)
□ No conduit required for low voltage
□ Connect to light fixtures
□ Timer on transformer typical
□ Much easier than line voltage

Detached Structure Feeder:

Underground Feeder Method:
□ Size wire for loads in detached structure
□ Typical: 60A feeder (6 AWG) or 100A feeder (2 AWG)
□ Trench from main panel to detached structure
□ Install UF cable (if direct burial) or PVC with THWN
□ Burial depth: 24" for UF, 18" for PVC
□ Install disconnect at detached structure (required)
□ Install sub-panel in detached structure
□ Separate grounding at detached structure (ground rods)
□ Bond neutral-ground at detached structure sub-panel
□ Label circuits in both panels

Overhead Feeder Method:
□ More expensive but easier to troubleshoot
□ Install conduit (rigid or PVC) up building
□ Run wires overhead on poles or building
□ Must meet clearance requirements (10-12 feet typical)
□ Weather protection at all exposed points
□ Same sub-panel requirements as underground

SAFETY & WEATHERPROOFING:

Critical Weatherproofing Steps:
□ Caulk all box penetrations
□ Use weatherproof gaskets
□ Ensure covers seat properly
□ Test for water intrusion
□ Slope slightly downward (prevent water pooling)
□ Check annually for deterioration

Grounding Outdoors:
□ All outdoor receptacles grounded
□ All metal boxes grounded
□ Detached structures: Separate grounding system
□ Proper bonding of all metal components
□ Ground rods at detached structures

PHASE 4: INSPECTION

Rough-In Inspection (For Underground Work):

Inspector verifies:
□ Trenches at proper depth (24" UF, 18" PVC)
□ Conduit properly installed (if used)
□ Wire type appropriate (UF or THWN)
□ Wire sizing correct for circuit
□ Proper protection at risers
□ No damaged wire insulation
□ Underground route documented

If rough-in PASSES:
✓ Approved to backfill trenches
✓ Proceed with outlet/fixture installation

If rough-in FAILS:
✗ Inspector notes violations
✗ Fix before backfilling
✗ Re-inspection required

Final Inspection (After Completion):

Inspector verifies:
□ ALL outdoor receptacles GFCI protected
□ GFCI outlets functioning (will test EVERY outdoor outlet)
□ Weatherproof covers installed (in-use type)
□ WR (weather-resistant) receptacles used
□ Front + back outlets present (minimum requirement)
□ Outlets at proper height (ground level ≤6.5 feet)
□ Light fixtures exterior-rated
□ Proper grounding of all components
□ All connections tight
□ Boxes properly sealed against weather
□ Panel labeling complete
□ No exposed wiring
□ Burial depths adequate (if underground verified)

Testing by inspector:
- GFCI test button (will press on each outdoor outlet or test breaker)
- Outlet tester for proper wiring
- Verify 120V at receptacles
- Light fixtures function
- Weatherproof covers close properly

If final inspection PASSES:
✓ Work approved
✓ Certificate issued
✓ Can use outdoor circuits

If final inspection FAILS:
✗ Violations noted
✗ Fix and re-inspect
✗ Common: GFCI not working, non-weatherproof covers, improper burial depth

INSPECTOR CHECKLIST: Outdoor Circuits
================================================================================

WHAT INSPECTOR WILL VERIFY:

OUTDOOR RECEPTACLES:
□ Minimum 1 front + 1 back of house present
□ Ground level (≤6.5 feet above grade)
□ ALL outdoor receptacles GFCI protected (no exceptions)
□ GFCI test button works (inspector presses it)
□ GFCI trips when tested
□ GFCI resets properly
□ WR (weather-resistant) receptacles used
□ Weatherproof in-use covers installed
□ Covers close properly with plug inserted
□ Boxes properly sealed/caulked
□ Proper grounding

UNDERGROUND WIRING:
□ Proper wire type (UF cable or THWN in conduit)
□ Adequate burial depth (24" UF, 18" PVC, 6" RMC)
□ Conduit properly installed (if used)
□ Riser protection (conduit from ground to box)
□ No damaged wire insulation
□ Proper wire sizing for circuit
□ Warning tape above underground wiring (recommended)

OUTDOOR LIGHTING:
□ Fixtures exterior-rated (wet or damp location)
□ Proper mounting
□ Weatherproof boxes
□ Fixtures functioning
□ Switch accessible
□ Proper grounding

DETACHED STRUCTURE FEEDER:
□ Feeder wire sized for loads
□ Proper burial depth (if underground)
□ Disconnect at detached structure
□ Sub-panel properly installed
□ Separate grounding system (ground rods)
□ Neutral-ground bond at sub-panel only
□ All circuits labeled

CIRCUIT REQUIREMENTS:
□ Outdoor circuits properly sized (20A typical)
□ 20A circuits use 12 AWG wire
□ 15A circuits use 14 AWG wire
□ Proper breaker sizes
□ GFCI breakers if used (test button present)

WEATHERPROOFING:
□ All boxes weatherproof rated
□ Proper gaskets installed
□ Boxes caulked/sealed
□ No water entry points
□ Covers seat properly

PANEL:
□ All outdoor circuits labeled clearly
□ Proper breaker sizes
□ GFCI breakers tested (if used)
□ No double-tapping
□ Panel schedule accurate

COMMON INSPECTOR FINDINGS (Violations):

❌ VIOLATION 1: No GFCI on Outdoor Receptacles
   Problem: Outdoor outlets without GFCI protection
   Why it fails: Code requires GFCI on ALL outdoor receptacles
   Fix: Install GFCI outlets or GFCI breaker
   Reference: 2022 CEC 210.8(A)(3)
   Cost to fix: $20-40 per WR GFCI outlet or $40-80 for breaker

❌ VIOLATION 2: Non-Weatherproof Covers
   Problem: Standard indoor covers on outdoor outlets
   Why it fails: Must be weatherproof in-use type
   Fix: Replace with weatherproof in-use covers
   Reference: 2022 CEC 406.9(B)
   Cost to fix: $10-30 per cover

❌ VIOLATION 3: Non-WR Receptacles Outdoors
   Problem: Standard receptacles used instead of weather-resistant
   Why it fails: Outdoor locations require WR receptacles
   Fix: Replace with WR-rated receptacles
   Reference: 2022 CEC 406.12
   Cost to fix: $15-30 per receptacle

❌ VIOLATION 4: GFCI Not Functioning
   Problem: GFCI test button doesn't trip circuit
   Why it fails: Defective GFCI or wiring error
   Fix: Replace GFCI or correct wiring
   Reference: 2022 CEC 210.8(D)
   Cost to fix: $20-50

❌ VIOLATION 5: Improper Burial Depth
   Problem: Underground wiring too shallow
   Why it fails: Code specifies minimum depths for safety
   Fix: Re-trench and bury to proper depth
   Reference: 2022 CEC 300.5(A)
   Cost to fix: $200-800 (excavation + reburial)

❌ VIOLATION 6: Missing Front or Back Outlet
   Problem: House doesn't have required outdoor outlets
   Why it fails: Code requires 1 front + 1 back minimum
   Fix: Install missing outlet(s)
   Reference: 2022 CEC 210.52(E)
   Cost to fix: $150-400 per outlet

❌ VIOLATION 7: Outdoor Outlet Above 6.5 Feet
   Problem: Ground level outlet installed too high
   Why it fails: Must be accessible within 6.5 feet of grade
   Fix: Relocate outlet lower or add second outlet
   Reference: 2022 CEC 210.52(E)(1)
   Cost to fix: $150-400

❌ VIOLATION 8: Non-Exterior Rated Fixtures
   Problem: Indoor light fixtures used outdoors
   Why it fails: Must be rated for wet or damp location
   Fix: Replace with exterior-rated fixtures
   Reference: 2022 CEC 410.10
   Cost to fix: $50-200 per fixture

❌ VIOLATION 9: Box Not Sealed Against Weather
   Problem: Outdoor boxes not caulked or sealed
   Why it fails: Water intrusion risk
   Fix: Caulk all box penetrations
   Reference: 2022 CEC 314.15
   Cost to fix: $25-75 (caulking labor)

❌ VIOLATION 10: Wrong Wire Type Underground
   Problem: Indoor Romex (NM cable) buried instead of UF
   Why it fails: NM not rated for wet/underground locations
   Fix: Replace with UF cable or THWN in conduit
   Reference: 2022 CEC 300.5(B)
   Cost to fix: $400-1,500 (excavate + replace)

  │  └─ YES → PERMIT REQUIRED

  │  └─ NO PERMIT (minor repair per Section 82-3(a))
  │     But GFCI MANDATORY for all outdoor outlets
  │     Must use WR receptacles and weatherproof covers
  │

  │  └─ NO PERMIT (minor repair)

  │

COMMON VIOLATIONS: Outdoor Circuits
================================================================================

TOP 10 OUTDOOR ELECTRICAL VIOLATIONS:

VIOLATION 1: No GFCI on Outdoor Receptacles
❌ Problem: Outdoor outlets without GFCI protection
   Why it fails: Code requires GFCI on ALL outdoor receptacles
   How to fix: Install GFCI outlets or GFCI breaker
   Reference: 2022 CEC 210.8(A)(3)
   Cost to fix: $20-40 per WR GFCI outlet or $40-80 for breaker

VIOLATION 2: Non-Weatherproof Covers
❌ Problem: Standard indoor covers used outdoors
   Why it fails: Must be weatherproof in-use type
   How to fix: Replace with weatherproof in-use covers
   Reference: 2022 CEC 406.9(B)
   Cost to fix: $10-30 per cover

VIOLATION 3: Non-WR Receptacles Outdoors
❌ Problem: Standard receptacles instead of weather-resistant
   Why it fails: Outdoor requires WR-rated
   How to fix: Replace with WR receptacles
   Reference: 2022 CEC 406.12
   Cost to fix: $15-30 per receptacle

VIOLATION 4: GFCI Not Functioning
❌ Problem: GFCI test button doesn't work
   Why it fails: Defective GFCI or wiring error
   How to fix: Replace GFCI or correct wiring
   Reference: 2022 CEC 210.8(D)
   Cost to fix: $20-50

VIOLATION 5: Improper Burial Depth
❌ Problem: Underground wiring too shallow
   Why it fails: Safety requirement (protection from digging)
   How to fix: Re-trench to proper depth
   Reference: 2022 CEC 300.5(A)
   Cost to fix: $200-800

VIOLATION 6: Missing Required Outdoor Outlets
❌ Problem: No front or back outdoor outlet
   Why it fails: Code requires minimum 1 front + 1 back
   How to fix: Install missing outlet(s)
   Reference: 2022 CEC 210.52(E)
   Cost to fix: $150-400 per outlet

VIOLATION 7: Outdoor Outlet Too High
❌ Problem: Ground level outlet above 6.5 feet
   Why it fails: Accessibility requirement
   How to fix: Relocate lower or add second outlet
   Reference: 2022 CEC 210.52(E)(1)
   Cost to fix: $150-400

VIOLATION 8: Non-Exterior Rated Fixtures
❌ Problem: Indoor fixtures used outdoors
   Why it fails: Must be wet/damp location rated
   How to fix: Replace with exterior-rated fixtures
   Reference: 2022 CEC 410.10
   Cost to fix: $50-200 per fixture

VIOLATION 9: Box Not Sealed
❌ Problem: Outdoor boxes not caulked
   Why it fails: Water intrusion risk
   How to fix: Caulk all penetrations
   Reference: 2022 CEC 314.15
   Cost to fix: $25-75

VIOLATION 10: Wrong Underground Wire Type
❌ Problem: NM cable buried instead of UF
   Why it fails: NM not rated for underground
   How to fix: Replace with UF or THWN in conduit
   Reference: 2022 CEC 300.5(B)
   Cost to fix: $400-1,500

PREVENTION STRATEGIES:

Before starting work:
✓ Plan outlet locations (front + back minimum)
✓ Verify GFCI on ALL outdoor outlets
✓ Use WR receptacles and weatherproof covers
✓ Check burial depth requirements
✓ Use proper wire type (UF or THWN)
✓ Hire licensed C-10 contractor

During installation:
✓ Use GFCI breaker (most cost-effective)
✓ Test GFCI before final inspection
✓ Caulk all outdoor boxes
✓ Verify burial depths
✓ Mark underground routes

Before inspection:
✓ Test ALL GFCI outlets (press test button)
✓ Verify weatherproof covers close properly
✓ Check all fixtures exterior-rated
✓ Verify front + back outlets present
✓ Review circuit directory

RAG QUERY EXAMPLES
================================================================================

Q: "Do I need GFCI for outdoor outlets?"
A: "YES. ALL outdoor receptacles (125V-250V) require GFCI protection (2022 CEC 210.8(A)(3)). 
No exceptions. This includes front, back, patio, deck, carport outlets. Must also use 
WR (weather-resistant) receptacles and weatherproof in-use covers. Inspector WILL test 
every outdoor outlet. Install GFCI outlets ($20-40 WR type) or GFCI breaker at panel ($40-80)."

Q: "How many outdoor outlets are required?"
A: "Minimum: 1 front + 1 back of house (2022 CEC 210.52(E)). Must be ground level 
(≤6.5 feet above grade). All must be GFCI protected. Recommended: Additional outlets on 
each side, patio/deck areas, garage exterior. Permit required for new circuits via 
EPIC-LA: epicla.lacounty.gov"

Q: "How deep do I bury outdoor electrical wire?"
A: "Burial depths (2022 CEC 300.5(A)): UF cable direct burial = 24" minimum (or 18" with 
2" concrete on top, or 12" if GFCI protected). THWN in Schedule 40 PVC = 18" minimum. 
Rigid metal conduit = 6" minimum. Most residential: Use UF cable buried 24" deep. 
Inspector verifies depth at rough-in inspection before backfill."

Q: "How much does outdoor electrical cost?"
A: "Typical costs: Basic 2 GFCI outlets ($790-1,550), Underground circuit with 4 outlets 
($1,345-2,730), Outdoor lighting package ($1,688-3,615), Detached garage feeder 
($2,710-5,810). Includes permit ($100-400), materials, labor. Low voltage landscape lighting 
($680-1,500) requires no permit. Get 3 quotes from licensed C-10 contractors."

Q: "Do I need permit for outdoor outlets?"
A: "Depends. New outdoor circuits: YES permit required. Fee: $100-200 via EPIC-LA 
(epicla.lacounty.gov). Replacing outlets same location: NO permit (Section 82-3(a)). 
Low voltage landscape lighting (12V/24V): NO permit. Line voltage landscape lighting 
(120V): YES permit required. Licensed C-10 contractor pulls permit."

Q: "What's the difference between weatherproof covers?"
A: "Two types: (1) Standard weatherproof: Covers outlet when not in use, but open when 
plug inserted (NOT code compliant outdoors). (2) In-use weatherproof covers: Stay closed 
with plug inserted (REQUIRED for outdoor outlets per 2022 CEC 406.9(B)). Cost: $10-30. 
Horizontal or vertical orientation. Clear lid. Inspector will fail non-in-use covers."

Q: "Can I use regular Romex outdoors underground?"
A: "NO. Indoor Romex (NM cable) NOT rated for wet/underground locations. Must use: 
(1) UF (underground feeder) cable for direct burial, OR (2) THWN wire in PVC conduit. 
Using NM cable underground will fail inspection. Inspector checks at rough-in. Cost to 
fix: $400-1,500 (excavate + replace). Reference: 2022 CEC 300.5(B)."

Q: "Do I need permit for low voltage landscape lighting?"
A: "NO permit needed for low voltage (12V/24V) landscape lighting systems (low voltage 
exempt). BUT transformer that powers system must plug into GFCI-protected outlet. 
Advantages: No permit, easier installation, DIY-friendly, less expensive ($680-1,500 
typical). Disadvantage: Less bright than 120V line voltage lighting."
