Q1: "What's the difference between Class A and standard GFCI?"
A: "CLASS A GFCI: 5mA trip (5 milliamps maximum before tripping)
    STANDARD GFCI: 30mA trip (30 milliamps maximum before tripping)
    
    IN WATER: Body resistance drops to 1,000 ohms (from 100,000 ohms dry)
    Standard 30mA = 30V across heart = LETHAL muscle paralysis
    Class A 5mA = 5V across heart = SAFE (barely noticeable)
    
    POOLS: Require Class A GFCI (6x more sensitive)
    INSPECTOR: Will verify 'Class A' label on breaker

Q2: "Why is bonding so critical for pool safety?"
A: "BONDING PURPOSE: Equalizes electrical potential between all metal
    WITHOUT BONDING: Voltage differences create shock paths through water
    WITH BONDING: All equipment at same voltage = no shock path
    
    EXAMPLE: Without bonding, person in water touching pump + ladder = SHOCK
    WITH BONDING: Same contact = no shock (both at same potential)
    
    REQUIREMENT: #8 AWG copper connecting pump, filter, heater, light, ladder
    INSPECTOR: Tests continuity of entire bonding system
    MISSING BONDING = IMMEDIATE FAILURE + potential electrocution"

Q3: "Ground rod must be in soil - why not concrete?"
A: "CONCRETE: Non-conductive (doesn't conduct electricity to earth)
    SOIL: Conductive (provides true earth connection)
    
    GROUNDING PURPOSE: Provides escape path for fault current to earth
    IN CONCRETE: Fault current has nowhere to go = DANGEROUS
    IN SOIL: Fault current conducted safely to earth
    
    MEASUREMENT: Resistance should measure <25 ohms to earth
    INSPECTOR: Tests with specialized meter
    GROUND IN CONCRETE = INEFFECTIVE + FAILED INSPECTION"

Q4: "How far must pool equipment be from water?"

    EXAMPLE: If pool edge is at position X, equipment must be at position X+6'
    EXCEPTION: Bonded equipment only (already at same potential)
    TOO CLOSE = Must completely relocate installation"

Q5: "Can I use regular household wiring for pool lights?"
A: "NO! POOLS REQUIRE SPECIALIZED LIGHTING:
    
    VOLTAGE: 12V low voltage (NOT 120V household)
    TRANSFORMER: Must be ground-fault protected
    NICHE: Must be completely water-sealed (waterproof)
    WIRING: Pool-rated cable only (special insulation)
    
    WHY: Underwater + 120V = instant electrocution/death
    WHY: 12V + sealed + grounded = SAFE electrical connection
    
    USING HOUSEHOLD WIRING = IMMEDIATE FAILURE + DEATH HAZARD
    This is the highest electrocution risk in pool electrical"

REQUIREMENT 1: CLASS A GFCI PROTECTION (Most Critical for Safety)
════════════════════════════════════════════════════════════════════════════

REQUIREMENT (LIFE-SAFETY CRITICAL):
Source: 2022 CEC Section 680.5(B) [web:82]
Rule: All 125V pool circuits require CLASS A GFCI (5mA trip threshold)
      NOT standard 30mA GFCI - CLASS A IS MANDATORY
Applies to: All electrical circuits in/around pool area

🚨 WHY CLASS A GFCI IS CRITICAL (ELECTROCUTION PREVENTION):

HUMAN PHYSIOLOGY IN WATER:
• Dry skin resistance: ~100,000 ohms
• Wet skin resistance: ~1,000 ohms (100x less!)
• Water resistance: ~1,000 ohms (same!)
• Total pool contact resistance: ~2,000 ohms

CURRENT EFFECTS (Across chest/heart):
• 1 mA: Barely noticeable, no danger
• 5 mA: Startling but escape possible
• 10 mA: Muscle paralysis begins, can't let go
• 20 mA: Severe paralysis
• 50+ mA: Ventricular fibrillation (death)

STANDARD 30mA GFCI IN POOL:
• Person touches pool light: ~15V from fault
• Current through body: 15V ÷ 2,000Ω = 7.5mA
• At 7.5mA: Muscle paralysis onset (can't escape!)
• 30mA trip: Delayed 5-8 milliseconds (LETHAL)
• RESULT: Electrocution/drowning

CLASS A 5mA GFCI IN POOL:
• Person touches pool light: ~15V from fault
• Current through body: 15V ÷ 2,000Ω = 7.5mA
• Class A GFCI trips: Immediately (<1 millisecond)
• RESULT: Harmless (person unharmed, escapes easily)

INSTALLATION REQUIREMENT:
• Install at main pool panel (protects all 125V pool circuits)
• Breaker must be labeled "CLASS A GFCI" (not standard)
• Must be 100% accessible and tested
• Cannot be bypassed or defeated

⚡ POOL ELECTRICIAN QUICK TIP:
• Specify "Class A GFCI breaker" when ordering
• Label panel clearly "CLASS A GFCI - POOL CIRCUITS"
• Cost: $40-60 (slightly more than standard breaker)
• Order specifically for pool use (not general purpose)
• Always test before inspection (5mA sensitivity)
• Document Class A GFCI installation with photos

🚨 INSPECTOR FOCUS - CLASS A GFCI CHECK:
• Verifies breaker is labeled "Class A"
• May test trip sensitivity with specialized equipment
• Confirms ALL 125V pool circuits have Class A protection
• Tests actual trip response (should be immediate)
• Checks breaker compatibility with panel
• Verifies accessibility and proper installation

💡 SAFETY IMPACT - WHY THIS SAVES LIVES:
• Standard GFCI fails in water environment (too slow)
• Class A GFCI designed specifically for water zones
• 5mA limit prevents ANY muscle paralysis
• Eliminates electrocution death hazard
• This single requirement prevents ~95% of pool electrocutions

COST: ~$50-60 for Class A GFCI breaker (worth every penny for safety!)

PERMIT VERIFICATION:
→ LA County requires Class A GFCI (Article 680 adoption)
→ Inspector specifically checks for Class A installation
→ Using standard GFCI = IMMEDIATE INSPECTION FAILURE

REQUIREMENT 2: BONDING - EQUALIZE ELECTRICAL POTENTIAL (Safety Critical)
════════════════════════════════════════════════════════════════════════════

REQUIREMENT (SHOCK PREVENTION):
Source: 2022 CEC Section 680.26 [web:82]
Rule: ALL metal components must be bonded with #8 AWG copper conductor
      Creates continuous electrical connection between all equipment
Applies to: Pool pump, filter, heater, light niche, ladder, metal decking, etc.

PURPOSE OF BONDING (ELECTROCUTION PREVENTION):

WITHOUT BONDING:
• Different equipment at different voltage potentials
• Person touching pump + ladder = voltage difference flows through body
• SHOCK PATH: Pump (V1) → Body → Ladder (V2) → Current flows = SHOCK!

WITH BONDING:
• All equipment bonded to same copper conductor
• All at same electrical potential (same voltage)
• Person touching pump + ladder = no voltage difference
• NO SHOCK PATH: Pump (V) → Body → Ladder (V) → NO current flows = SAFE!

BONDING COMPONENTS (WHAT MUST BE BONDED):

MUST BOND:
✓ Pool water (typically via pump bonding)
✓ Pump motor
✓ Filter equipment
✓ Pool heater
✓ Underwater light niche (metal housing)
✓ Pool ladder
✓ Metal pool deck/surround (if conductive)
✓ Any metal equipment within 6 feet of pool

DO NOT BOND (or separate rules):
✗ Wooden structures (non-conductive)
✗ Fiberglass (non-conductive)
✗ Non-metal components

BONDING CONDUCTOR SPECIFICATION:

SIZE: #8 AWG minimum (larger for big pools - verify with inspector)
MATERIAL: BARE COPPER only (not aluminum!)
INSTALLATION: 
• Run as continuous loop connecting all equipment
• No splices if possible (if necessary, use pressure connectors)
• Visible during rough-in inspection (before covering)
• Protected from damage if covered later

BONDING CONNECTIONS:
• Pump: Bonded to pump housing/motor frame
• Filter: Bonded to filter tank
• Heater: Bonded to heater housing
• Light niche: Bonded to metal niche frame
• Ladder: Bonded to ladder frame
• Deck: Bonded to metal decking (if present)

TESTING REQUIREMENT:
• Inspector will test continuity between ALL bonded components
• Using ohmmeter: Should read <1 ohm between any two bonded points
• If >1 ohm: Connection is inadequate, must be corrected

⚡ POOL ELECTRICIAN QUICK TIP:
• Order #8 AWG bare copper bonding wire (not stranded if possible)
• Create continuous loop during rough-in (visible for inspection)
• Connect with UL-listed pressure connectors or solder
• Label bonding connections at each component
• Test continuity with meter before inspection
• Document with photos showing all bonding connections
• Cost: $0.50-1.00 per foot (budget 50-100 feet for typical pool)

🚨 INSPECTOR FOCUS - BONDING CHECK:
• Checks for #8 AWG minimum conductor size
• Verifies ALL metal equipment is bonded
• Tests continuity between bonded components (ohmmeter test)
• Confirms connections are tight and secure
• Verifies visible bonding during rough-in
• May require opening covered areas to verify

💡 SAFETY IMPACT - WHY BONDING SAVES LIVES:
• Without bonding: Voltage differences = current through body = SHOCK
• With bonding: No voltage differences = no shock path = SAFE
• This requirement prevents shock deaths in pool area
• Bonding is as critical as GFCI for pool safety

COMMON BONDING FAILURES:
❌ Using aluminum conductor (degrades, poor conductivity)
❌ Smaller than #8 AWG (insufficient conductivity)
❌ Spliced connections (weak points, corrosion)
❌ Missing components (pump, heater, ladder not bonded)
❌ Poor connections (loose, corroded)
→ All result in inadequate voltage equalization = SHOCK HAZARD

REQUIREMENT 3: GROUNDING - EARTH FAULT PROTECTION
════════════════════════════════════════════════════════════════════════════

REQUIREMENT (FAULT PROTECTION):
Source: 2022 CEC Section 680.23 [web:82]
Rule: Dedicated grounding rod driven into SOIL (not concrete)
      Measures <25 ohms resistance to earth (inspector tests)
Applies to: Main pool electrical ground reference

PURPOSE OF GROUNDING (FAULT CURRENT PATH):

GROUNDING CIRCUIT:
• Ground rod in soil → Copper conductor → Pool equipment → Ground system
• Purpose: Provides escape path for fault current to earth
• If fault occurs: Current goes to ground (not through person)

GROUND ROD REQUIREMENT:

MATERIAL: Copper rod (8 feet long, 5/8" diameter typical)
INSTALLATION: Driven vertically into soil (minimum 8 feet deep contact)
LOCATION: Within or near pool electrical system (accessible area)
DO NOT: Embed in concrete, asphalt, or non-conductive material

WHY NOT CONCRETE:
• Concrete is non-conductive (even when wet)
• Current cannot escape to earth through concrete
• Ground rod in concrete = ineffective + dangerous

RESISTANCE MEASUREMENT:
• Inspector measures with specialized meter (ground resistance tester)
• Target: <25 ohms resistance to earth
• If >25 ohms: Must add additional ground rods or improve
• Multiple rods connected in parallel if needed

GROUNDING CONDUCTOR:
• Size: #8 AWG copper minimum (may be larger)
• From: Ground rod → Equipment ground connection
• Installation: Protected from damage (buried if needed)

⚡ POOL ELECTRICIAN QUICK TIP:
• Install ground rod in soil AWAY from concrete pad
• Drive 8+ feet into ground (use impact driver or sledgehammer)
• Verify soil contact (not concrete, asphalt, or rock layer)
• Connect #8 AWG copper from rod to equipment ground
• Allow inspector to measure resistance (bring tester)
• Budget: Ground rod + labor for installation

🚨 INSPECTOR FOCUS - GROUNDING CHECK:
• Verifies ground rod in SOIL (not concrete)
• Measures ground resistance with specialized meter
• Confirms <25 ohm resistance to earth
• Checks copper conductor connection quality
• Verifies proper sizing (#8 AWG minimum)
• Tests continuity from rod to equipment ground

💡 SAFETY IMPACT - WHY GROUNDING PREVENTS HAZARDS:
• Without proper grounding: Fault current has nowhere to go
• With proper grounding: Fault current escapes safely to earth
• Prevents accumulation of dangerous voltage
• Backup safety system if bonding fails

REQUIREMENT 4: EQUIPMENT DISTANCE FROM POOL (6 Feet Minimum)
════════════════════════════════════════════════════════════════════════════

REQUIREMENT (CONTACT PREVENTION):
Source: 2022 CEC Section 680.9 [web:82]
Rule: Equipment must be minimum 6 feet from pool water edge
      Measured horizontally (not vertical distance)
Applies to: Pump, filter, heater, transformer, disconnect, any electrical equipment

DISTANCE MEASUREMENT:

MEASUREMENT POINT: From pool water edge (not concrete surround)
INCLUDES: Horizontal distance to nearest equipment point
WHAT COUNTS AS EQUIPMENT:
✓ Pump housing (closest point)
✓ Filter tank (closest point)
✓ Heater (closest point)
✓ Transformer (closest point)
✓ Disconnect switch (closest point)
✓ Any metal electrical component

EXAMPLE LAYOUT:
[Pool water] ----6 feet minimum---- [Equipment line]
            ←─────measurement─────→
            
Inspector measures from water edge to nearest equipment point

WHY 6 FEET:
• Person in pool cannot reach equipment
• Prevents accidental touching of electrical components
• Minimum safe distance for pool area layout
• Accounts for various pool activities

EXCEPTIONS (If bonded):
• Some bonded metal decking may be allowed closer
• Only if properly bonded per 2022 CEC rules
• Verify with inspector (don't assume)

⚡ POOL ELECTRICIAN QUICK TIP:
• Measure 6 feet from pool water edge BEFORE ordering equipment
• Plan equipment layout during design phase
• Position pump/filter at safe distance from water
• Transformer and disconnect also must be 6+ feet away
• Mark distance with tape during rough-in (show inspector)
• Document with photos showing measurement

🚨 INSPECTOR FOCUS - DISTANCE CHECK:
• Uses tape measure to verify 6+ feet from pool edge
• Checks ALL equipment (pump, filter, heater, transformer, disconnect)
• If any equipment too close: Fails inspection
• Requires relocation before approval
• Will re-measure after relocation to verify compliance

💡 SAFETY IMPACT - PREVENTS DIRECT CONTACT HAZARD:
• 6-foot distance prevents someone reaching equipment from water
• Combined with bonding/GFCI = complete protection
• This requirement prevents accidental electrocution

COMMON DISTANCE FAILURES:
❌ Pump too close to pool edge (measured to water)
❌ Transformer closer than 6 feet
❌ Disconnect switch within 6-foot zone
❌ Any equipment too close = INSPECTION FAILURE + relocation required

PRE-INSPECTION POOL ELECTRICAL CHECKLIST (Ready to Use)
════════════════════════════════════════════════════════════════════════════

🛠️ COMPLETE PRE-INSPECTION PROCEDURE - Day Before Inspection:

CHECKLIST SECTION 1: CLASS A GFCI VERIFICATION
□ Locate GFCI breaker at main panel
□ Verify breaker is labeled "CLASS A GFCI" (not standard)
□ Turn off all pool circuits at breaker
□ Plug lamp into 125V pool outlet (should be off now)
□ Turn breaker back ON
□ Lamp should be ON now
□ Press TEST button on GFCI breaker
□ Lamp should turn OFF immediately (within 1 millisecond)
□ Press RESET button on GFCI breaker
□ Lamp should turn back ON
□ Repeat test 3 times (all pass = READY)
□ Document: "Class A GFCI tested and operational"

CHECKLIST SECTION 2: BONDING VERIFICATION
□ Visually inspect #8 AWG bonding conductor (should be visible in rough-in)
□ Verify copper material (NOT aluminum)
□ Check connections at: Pump, Filter, Heater, Light Niche, Ladder, Metal Deck
□ Test bonding continuity at EACH connection with ohmmeter
   □ Pump to Filter: Should read <1 ohm
   □ Filter to Heater: Should read <1 ohm
   □ Heater to Light Niche: Should read <1 ohm
   □ Light Niche to Ladder: Should read <1 ohm
   □ Ladder to Metal Deck: Should read <1 ohm
□ If ANY reading >1 ohm: Connection needs repair (tighten or re-solder)
□ Document: "All bonding connections verified <1 ohm"

CHECKLIST SECTION 3: GROUNDING VERIFICATION
□ Locate ground rod (should be visible in soil, not concrete)
□ Verify ground rod is in SOIL (not embedded in concrete)
□ Verify #8 AWG copper conductor from rod to equipment
□ Test ground resistance with meter (if possible)
   □ Target: <25 ohms to earth
   □ If unable to test: Inspector will test at inspection
□ Document: "Ground rod in soil, connection verified"

CHECKLIST SECTION 4: EQUIPMENT DISTANCE VERIFICATION
□ Measure from pool water edge to pump motor (closest point)
   □ Minimum: 6 feet away ✓ or ✗
□ Measure from pool water edge to filter (closest point)
   □ Minimum: 6 feet away ✓ or ✗
□ Measure from pool water edge to heater (closest point)
   □ Minimum: 6 feet away ✓ or ✗
□ Measure from pool water edge to transformer (closest point)
   □ Minimum: 6 feet away ✓ or ✗
□ Measure from pool water edge to disconnect (closest point)
   □ Minimum: 5 feet away ✓ or ✗
□ If ANY measurement too close: Relocate equipment BEFORE inspection
□ Document: "All equipment verified 6+ feet from pool edge"

CHECKLIST SECTION 5: DISCONNECT MEANS VERIFICATION
□ Locate manual disconnect switch (5+ feet from pool)
□ Verify switch is accessible (not buried or blocked)
□ Test switch operation (ON/OFF function works)
□ Verify switch is labeled "POOL EQUIPMENT DISCONNECT"
□ Document: "Disconnect switch functional and accessible"

CHECKLIST SECTION 6: UNDERWATER LIGHTING VERIFICATION
□ Light niche is sealed (watertight, no cracks)
□ Transformer is protected (weatherproof, accessible)
□ Verify lighting voltage (should be 12V low voltage)
□ Test lighting operation (lights turn on/off properly)
□ Verify wiring is pool-rated cable (not standard)
□ Document: "Underwater lighting sealed and operational"

CHECKLIST SECTION 7: DOCUMENTATION & PHOTOS
□ Take photos of: GFCI breaker, bonding connections, ground rod, equipment distance
□ Create summary document with all checklist items
□ Note any corrections needed BEFORE inspector arrives
□ Schedule any needed repairs (don't wait for inspection failure)

POOL ELECTRICAL - INSPECTION TIMELINE & FAILURE RECOVERY
════════════════════════════════════════════════════════════════════════════

TYPICAL POOL INSPECTION SCHEDULE:

ROUGH-IN INSPECTION (Before pool filling):
• Inspector checks: Bonding visibility, distance, grounding, GFCI
• Time from request: 1-4 weeks (depending on season - see File 4)
• If PASSES: Proceed with pool filling and final connections
• If FAILS: Note violations, correct, re-inspect (another 1-4 weeks)

FINAL INSPECTION (After pool complete):
• Inspector checks: All systems operational, bonding tight, grounding measured
• Time from rough-in: 2-4 weeks
• Tests: GFCI functionality, ground resistance <25 ohms, bonding continuity
• If PASSES: Final approval, pool can be used
• If FAILS: Correct violations, wait for re-inspection

COMMON INSPECTION FAILURES (Prevention):

FAILURE 1: "Class A GFCI not installed"
PREVENTION: Use Class A breaker, not standard (verify before ordering)
FIX TIME: 1 hour (swap breaker)
RE-INSPECTION WAIT: 1-4 weeks

FAILURE 2: "Bonding connections not tight"
PREVENTION: Pre-inspect day before (use ohmmeter, verify <1 ohm)
FIX TIME: 1-2 hours (re-tighten connections)
RE-INSPECTION WAIT: 1-4 weeks

FAILURE 3: "Equipment too close to pool"
PREVENTION: Measure 6 feet before installation (don't guess)

POOL ELECTRICAL - MYTHS vs REALITY
════════════════════════════════════════════════════════════════════════════

❌ MYTH 1: "Standard GFCI is fine for pools (cost saving)"
✅ REALITY: Pool requires Class A GFCI (5mA, not 30mA)
   REASON: Standard GFCI too slow in water environment = LETHAL
   FACT: 30mA causes muscle paralysis in water
   FACT: 5mA Class A prevents paralysis hazard
   INSPECTOR: Will check for "Class A" label = FAIL if missing
   COST DIFFERENCE: Only $10-15 more than standard
   VERDICT: Class A is NON-NEGOTIABLE for safety

❌ MYTH 2: "Ground rod in concrete is acceptable (easier to install)"
✅ REALITY: Ground rod MUST be in SOIL (not concrete)
   REASON: Concrete is non-conductive = ineffective ground
   CONSEQUENCE: Fault current has no escape path to earth
   INSPECTOR: Will check ground rod location = FAIL if in concrete
   FIX COST: $200-400 to relocate (major excavation)
   VERDICT: Must install properly in soil from start

❌ MYTH 3: "Bonding is optional (cost saving)"
✅ REALITY: Bonding is CODE REQUIRED (not optional)
   REASON: Bonding equalizes voltage = prevents shock
   WITHOUT BONDING: Voltage differences = shock paths = ELECTROCUTION
   INSPECTOR: Tests continuity of bonding system
   CONSEQUENCE: Missing bonding = INSPECTION FAILURE + safety hazard
   VERDICT: Bonding is non-negotiable safety requirement

❌ MYTH 4: "Equipment can be closer than 6 feet if bonded"
✅ REALITY: 6-foot distance is MINIMUM (bonding or not)
   REASON: Prevents reaching equipment from water
   EXCEPTION: Some bonded metal decking allowed closer (verify with inspector)
   INSPECTOR: Measures with tape = FAIL if closer than specified
   CONSEQUENCE: Must relocate = expensive + time-consuming
   VERDICT: Plan layout carefully, measure before ordering

❌ MYTH 5: "Old pools don't need upgrades (already grandfathered in)"
✅ REALITY: Any NEW electrical work must meet CURRENT code
   REASON: Code changes for safety improvements
   CONSEQUENCE: Repairs/upgrades must use current code
   INSPECTOR: Will require current code compliance
   VERDICT: Class A GFCI, bonding, grounding per current code

❌ MYTH 6: "I can use regular household wire for pool lighting"
✅ REALITY: Pool lighting requires specialized low-voltage wiring
   REASON: Underwater = highest electrocution risk
   REQUIREMENT: 12V transformer + pool-rated cable + sealed niche
   CONSEQUENCE: Regular wire = IMMEDIATE ELECTROCUTION HAZARD
   INSPECTOR: Will find this = instant FAILURE
   VERDICT: Only specialized pool lighting allowed

❌ MYTH 7: "Pool electrical is simple DIY work"
✅ REALITY: Pool electrical is HIGHLY SPECIALIZED + DANGEROUS
   REASON: Electrocution hazard, specialized codes, complex bonding
   REQUIREMENT: Licensed electrician recommended (verify with inspector)
   CONSEQUENCE: DIY errors = electrocution death, code violations
   INSPECTOR: May question if DIY work
   VERDICT: Hire licensed pool electrician for safety

INSPECTOR COMMUNICATION - WHAT TO TELL INSPECTOR
════════════════════════════════════════════════════════════════════════════

WHEN REQUESTING ROUGH-IN INSPECTION (EPIC-LA):
"Inground swimming pool electrical system ready for rough-in inspection.
Installation includes: Class A GFCI protection, bonding system (#8 AWG copper),
grounding rod in soil, equipment 6+ feet from pool edge, underwater lighting
system, pump and filter circuits. Ready for verification."

INSPECTOR ARRIVES FOR ROUGH-IN:
Point out:
• GFCI breaker location (labeled "CLASS A")
• Bonding conductor connections (all visible)
• Ground rod location (in soil, not concrete)
• Equipment placement (6+ feet from pool)
• Lighting niche (sealed, transformer protected)
• Disconnect switch (accessible, 5+ feet away)

IF INSPECTOR ASKS QUESTIONS:
Q: "Is this Class A GFCI?"
A: "Yes, this is a Class A breaker rated for 5mA trip threshold,
    designed for pool use per 2022 CEC 680.5(B)."

Q: "How is the bonding system installed?"
A: "All metal equipment is connected with #8 AWG bare copper conductor.
   Pump, filter, heater, light niche, ladder, and metal decking are all bonded.
   Continuity tested at all connection points."

Q: "Where is the grounding rod?"
A: "Ground rod is installed in soil approximately [distance] feet from pool.
   We measured [resistance] ohms to earth resistance."

Q: "Is equipment 6 feet from pool?"
A: "Yes, all equipment is minimum 6 feet from the pool water edge.
   We measured with tape to verify compliance."

AFTER INSPECTION:
If PASSES: "Great! Proceeding to fill pool and complete final connections."
If FAILS: "Understand. We'll correct the noted violations and schedule re-inspection."
