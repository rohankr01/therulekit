PRACTICAL GUIDE: Garage Electrical Installation
================================================================================

STEP-BY-STEP GARAGE CIRCUIT INSTALLATION:

PHASE 1: PLANNING & DESIGN

1. Count Required Circuits
   Minimum per 2022 CEC:
   □ 1× 20A receptacle circuit (GFCI required)
   □ 1× 15-20A lighting circuit
   
   Recommended additions:
   □ 1× 15A garage door opener (dedicated)
   □ 1× 20A workshop/workbench (GFCI)
   □ 1× 40-50A EV charger (if applicable)
   □ 1× 240V for heavy equipment (if needed)

2. Plan Outlet Locations
   Code requirements:
   - Minimum: 1 receptacle in garage (for 1-2 car garage)
   - Recommended: 1 outlet every 6 feet around walls
   - Workbench: 2-4 outlets (GFCI protected)
   - Near garage door: 1 outlet (for opener if not hardwired)
   
   Practical recommendations:
   - Each wall: At least 1 outlet
   - Workbench area: 2-4 outlets on dedicated circuit
   - Near entry door: 1 outlet (convenience)
   - Freezer location: 1 dedicated outlet (GFCI required!)
   - Vehicle parking area: Consider future EV charging

3. Plan Lighting
   Lighting requirements:
   - Minimum: 1 light fixture with wall switch at entry
   - Recommended: Multiple fixtures (proper illumination)
   - Switch location: At each entry point
   - Consider: Motion sensor or photo-eye control
   
   Lighting recommendations:
   - General: LED shop lights (4-8 fixtures)
   - Task lighting: Over workbench
   - Exterior: Light above garage door
   - Minimum illumination: 50 lumens per sq ft

4. Plan Garage Door Opener Circuit
   Garage door opener options:
   
   Option 1: Plug-in (Most common)
   - Install receptacle near garage door opener location
   - GFCI required (garage receptacle)
   - Height: Near ceiling (7-8 feet)
   - Dedicated circuit recommended but not required
   
   Option 2: Hardwired
   - Direct connection to opener
   - GFCI not required (not receptacle)
   - Disconnect switch required within sight
   - Dedicated circuit recommended

5. Determine Wire Sizing
   20A receptacle circuits: 12 AWG copper wire
   15A lighting circuits: 14 AWG copper wire
   40-50A EV charger: 6 or 8 AWG copper
   
   Distance considerations:
   - Most garages close to panel (<50 feet)
   - Voltage drop typically not issue
   - Use 12 AWG for all 20A circuits

6. Check Panel Capacity
   Count available breaker slots:
   - Need 2-5 slots for garage circuits
   - If insufficient: Consider sub-panel
   - Verify amperage capacity adequate
   
   Load calculation:
   - General receptacles: 1,800 watts (20A circuit)
   - Lighting: 1,440 watts (15A circuit)
   - Garage door opener: 720 watts (typical)
   - EV charger: 9,600 watts (40A, 240V)
   - Total must not exceed service capacity

PHASE 2: PERMIT APPLICATION

1. Determine if Permit Needed
   Permit REQUIRED for:
   ✓ New garage circuits
   ✓ Relocating outlets
   ✓ Adding garage door opener circuit
   ✓ Adding EV charger
   ✓ Major garage electrical remodel
   
   Permit NOT REQUIRED for:
   ✗ Replacing outlets same location (Section 82-3(a))
   ✗ Replacing light fixtures same location
   ✗ Plugging in equipment to existing outlets

2. Apply via EPIC-LA
   URL: epicla.lacounty.gov
   Permit type: "Electrical Permit - Garage Circuits"
   
   Application details:
   □ Number of new circuits
   □ Outlet locations and count
   □ Lighting circuits
   □ Garage door opener circuit
   □ EV charger (if applicable)
   □ Work description
   □ Contractor license # (C-10 required)

3. Pay Permit Fee
   Fee structure:
   - Base: $36.00
   - Per circuit: ~$25-50 each (estimate)
   - Typical garage (2-3 circuits): $100-200
   - With EV charger: Add $100-150
   - Verify current: (626) 458-3180

4. Wait for Approval
   Timeline:
   - Simple garage: 5-7 days
   - With EV charger: 7-10 days
   - Complex workshop: 10-15 days

PHASE 3: INSTALLATION (Licensed Electrician)

Receptacle Circuits (20A, GFCI required):

General Receptacle Circuit:
□ Run 12/2 Romex from panel to garage
□ Install GFCI receptacle OR GFCI breaker at panel
□ Typical: 4-8 outlets around garage walls
□ All outlets must be GFCI protected
□ Height: 18-48" above floor
□ Spacing: Every 6 feet recommended
□ Label circuit "Garage Receptacles" in panel

⚠️ LA COUNTY CRITICAL REQUIREMENT:
   ALL garage receptacles require GFCI protection
   This includes:
   ✓ Freezer outlets (NO exception in LA County)
   ✓ Refrigerator outlets
   ✓ Dedicated appliance circuits
   ✓ Workshop outlets
   ✓ General outlets
   ✓ Garage door opener outlets (if receptacle)

Workbench Receptacle Circuit (20A, GFCI required):
□ Run 12/2 Romex from panel to workbench area
□ Install GFCI receptacle OR GFCI breaker
□ Typical: 2-4 outlets above workbench
□ Height: 42-48" above workbench surface
□ All outlets GFCI protected
□ Label circuit "Garage Workshop" in panel

Freezer/Refrigerator Circuit (20A, GFCI required in LA County):
□ Run 12/2 Romex to freezer/refrigerator location
□ Install GFCI receptacle OR GFCI breaker
□ Dedicated circuit recommended (prevents tripping)
□ GFCI REQUIRED in LA County (differs from state code!)
□ Label circuit "Garage Freezer" in panel

GFCI Installation Methods for Garage:

Option 1: GFCI Receptacles
  → Install GFCI as first outlet on circuit
  → Wire additional outlets to LOAD terminals
  → All downstream outlets protected
  → Test button on GFCI outlet
  → Cost: $15-30 per GFCI outlet
  → Advantage: Easy troubleshooting
  → Disadvantage: Multiple GFCI outlets expensive

Option 2: GFCI Breaker at Panel (RECOMMENDED)
  → Install GFCI breaker at panel
  → Entire circuit protected
  → All outlets downstream protected
  → Test button on breaker
  → Cost: $40-80 per GFCI breaker
  → Advantage: Single protection point, cost-effective
  → Disadvantage: Must go to panel to reset
  → RECOMMENDED for garage circuits

Lighting Circuit (15-20A, GFCI not required):

□ Run 14/2 or 12/2 Romex from panel
□ Install switch at entry (inside garage or outside)
□ Wire to light fixtures (multiple fixtures typical)
□ May use 3-way switches for multiple entries
□ GFCI not required (not receptacles)
□ Consider: Motion sensor or timer switch
□ Label circuit "Garage Lighting" in panel

Garage Door Opener Circuit (15A):

Option 1: Plug-in Installation (Most Common)
□ Run 14/2 Romex to opener location (near ceiling)
□ Install receptacle near garage door opener
□ GFCI required (garage receptacle)
□ Height: 7-8 feet (near opener)
□ May share with lighting circuit OR dedicated
□ Label circuit appropriately

Option 2: Hardwired Installation
□ Run 14/2 Romex to opener location
□ Hardwire directly to opener
□ Install disconnect switch within sight of opener
□ GFCI not required (not receptacle)
□ Dedicated circuit recommended
□ Label circuit "Garage Door Opener"

EV Charger Circuit (40-50A, 240V, GFCI required):
See cross-reference-ev-charging-LA.txt for complete details
□ Run 6/3 or 8/3 Romex (depends on amperage/distance)
□ Install 240V receptacle or hardwire
□ GFCI breaker required
□ Dedicated circuit required
□ Label circuit "EV Charger"

240V Equipment Circuit (30-50A, for welder/compressor):
□ Run 10/3, 8/3, or 6/3 Romex (depends on load)
□ Install 240V receptacle (appropriate type)
□ Dedicated circuit required
□ GFCI not typically required (check equipment specs)
□ Label circuit clearly

INSTALLATION BEST PRACTICES:

Outlet Height & Spacing:
- General outlets: 18-48" above floor
- Workbench outlets: 42-48" above bench surface
- Freezer outlet: 18-36" above floor (behind appliance)
- Garage door opener: 7-8 feet (near ceiling)
- Spacing: Every 6 feet around walls (recommended)

Wire Management:
□ Secure Romex every 4.5 feet
□ Staple within 12" of boxes
□ Protect from damage (especially in exposed garage)
□ No sharp bends
□ Proper box fill (not overcrowded)

Box Types for Garage:
- Surface-mount boxes: Common in garages (easier installation)
- Metal boxes: Better protection in exposed locations
- Weatherproof boxes: If near garage door or exterior
- Depth: 1.5" minimum for devices

Grounding in Garage:
□ All metal boxes grounded
□ All receptacles grounded
□ Proper grounding continuity
□ Green or bare copper ground wire

PHASE 4: INSPECTION

Rough-In Inspection (Before Drywall, if applicable):

Inspector verifies:
□ Romex properly secured and protected
□ Box locations correct (height, spacing)
□ Wire gauge appropriate (12 AWG for 20A, 14 AWG for 15A)
□ No damaged wire insulation
□ Proper box fill (not overcrowded)
□ Grounding continuity
□ No work outside permit scope
□ Proper protection in exposed areas

If rough-in PASSES:
✓ Approved for drywall/finishes (if applicable)

If rough-in FAILS:
✗ Inspector notes violations
✗ Fix before covering
✗ Re-inspection required

Final Inspection (After Completion):

Inspector verifies:
□ ALL garage receptacles GFCI protected
□ GFCI outlets functioning (will test EVERY outlet)
□ Freezer/refrigerator outlet has GFCI (LA County requirement!)
□ Outlets properly spaced
□ Proper outlet types (15A or 20A)
□ Lighting functioning
□ Garage door opener circuit proper
□ All connections tight
□ Cover plates installed
□ Panel labeling complete
□ No overloaded circuits
□ Proper grounding

⚠️ INSPECTOR FOCUS IN LA COUNTY GARAGES:
Inspector will specifically verify:
1. EVERY garage receptacle has GFCI protection
2. Freezer outlet has GFCI (this differs from state code)
3. Test EVERY GFCI outlet (press test button)
4. No exceptions for dedicated circuits

Testing by inspector:
- GFCI test button (will press on each garage outlet or test breaker)
- Outlet tester for proper wiring
- Verify 120V at receptacles
- Light fixtures function
- Garage door opener operates (if installed)

If final inspection PASSES:
✓ Work approved
✓ Certificate issued
✓ Can use garage

If final inspection FAILS:
✗ Violations noted
✗ Fix and re-inspect
✗ Common: Freezer outlet without GFCI, GFCI not working

□ At least 1 receptacle in garage (minimum)
□ Receptacles properly spaced (if multiple)
□ Proper outlet height (18-48" typical)

□ Proper grounding on all outlets
□ No reversed polarity
□ Accessible (not blocked by storage)

CIRCUIT REQUIREMENTS:
□ At least 1× 20A receptacle circuit serving garage
□ 20A circuit uses 12 AWG wire
□ Lighting circuit present
□ Garage door opener circuit proper
□ Dedicated circuits as needed (EV charger, workshop)
□ Proper circuit separation

LIGHTING:
□ At least 1 light fixture present
□ Switch at entry point
□ Proper fixture mounting
□ Fixtures functioning properly
□ Adequate illumination

GARAGE DOOR OPENER:
□ Proper circuit (receptacle with GFCI OR hardwired)
□ Disconnect switch if hardwired (within sight)
□ Functioning properly
□ Proper outlet location if plug-in (near ceiling)

WIRING:
□ 12 AWG wire for 20A circuits
□ 14 AWG wire for 15A circuits (lighting)
□ Romex properly secured (especially in exposed garage)
□ No damaged insulation
□ Proper box fill (not overcrowded)
□ All connections tight
□ Grounding continuity
□ Protection from physical damage

PANEL:
□ All garage circuits labeled clearly
□ Proper breaker sizes
□ GFCI breakers if used (test button present)
□ No double-tapping
□ Panel schedule accurate

SPECIAL LA COUNTY VERIFICATION:
□ Freezer/refrigerator outlet: GFCI protection verified
□ Inspector will test EVERY garage receptacle GFCI
□ No exceptions granted for "nuisance tripping"
□ LA County amendment enforced strictly

COMMON INSPECTOR FINDINGS (Violations):

❌ VIOLATION 1: Freezer Outlet Without GFCI (LA COUNTY SPECIFIC!)
   Problem: Freezer outlet installed without GFCI protection
   Why it fails: LA County removes exception for dedicated appliance circuits
   LA County requirement: ALL garage receptacles need GFCI (including freezers)
   Fix: Install GFCI outlet or GFCI breaker on that circuit
   Reference: 2022 CEC 210.8(A)(2) + LA County amendment
   Cost to fix: $15-30 (GFCI outlet) or $40-80 (GFCI breaker)
   
   ⚠️ NOTE: This is DIFFERENT from California state code!
   State code (2022 CEC): Allows exception for dedicated appliance circuits
   LA County code: NO exception - ALL garage outlets need GFCI

❌ VIOLATION 2: GFCI Not Functioning
   Problem: GFCI test button doesn't trip circuit
   Why it fails: Defective GFCI or wiring issue
   Fix: Replace GFCI or correct wiring
   Reference: 2022 CEC 210.8(D)
   Cost to fix: $15-50 (replace GFCI)

❌ VIOLATION 3: No GFCI on General Garage Outlets
   Problem: General use garage outlets without GFCI protection
   Why it fails: Code requires GFCI on ALL garage receptacles
   Fix: Install GFCI outlets or GFCI breaker
   Reference: 2022 CEC 210.8(A)(2)
   Cost to fix: $15-30 per outlet or $40-80 for GFCI breaker

❌ VIOLATION 4: Wrong Wire Gauge
   Problem: 14 AWG wire on 20A circuit
   Why it fails: Wire too small for breaker rating (fire hazard)
   Fix: Rewire with 12 AWG or reduce breaker to 15A
   Reference: 2022 CEC 210.19
   Cost to fix: $200-500 (rewiring) or $20 (reduce breaker)

❌ VIOLATION 5: Receptacle Polarity Reversed
   Problem: Hot and neutral wires swapped at outlet
   Why it fails: Safety hazard
   Fix: Correct wiring at outlet
   Reference: 2022 CEC 200.11
   Cost to fix: $25-50 (rewire outlet)

❌ VIOLATION 6: No Receptacle in Garage
   Problem: Garage has no electrical outlet
   Why it fails: Code requires minimum 1 receptacle
   Fix: Install at least 1 GFCI-protected receptacle
   Reference: 2022 CEC 210.52(G)
   Cost to fix: $100-200 (add outlet)

❌ VIOLATION 7: No Lighting in Garage
   Problem: Garage has no light fixture with switch
   Why it fails: Code requires lighting with wall switch
   Fix: Install light fixture and switch at entry
   Reference: 2022 CEC 210.70(A)(2)(a)
   Cost to fix: $100-250 (fixture + switch + wiring)

❌ VIOLATION 8: Garage Door Opener Outlet Not GFCI Protected
   Problem: Garage door opener plug-in receptacle without GFCI
   Why it fails: All garage receptacles need GFCI
   Fix: Install GFCI outlet or GFCI breaker
   Reference: 2022 CEC 210.8(A)(2)
   Cost to fix: $15-80 depending on method

❌ VIOLATION 9: Exposed Wiring Not Protected
   Problem: Romex cable exposed in garage without protection
   Why it fails: Vulnerable to physical damage
   Fix: Install conduit or run through studs
   Reference: 2022 CEC 334.15
   Cost to fix: $100-300 (conduit installation)

❌ VIOLATION 10: Missing Circuit Labeling
   Problem: Panel doesn't show garage circuits
   Why it fails: Code requires circuit directory
   Fix: Create accurate labels for all circuits
   Reference: 2022 CEC 408.4
   Cost to fix: $25-75 (circuit identification)

COMMON VIOLATIONS: Garage Circuits
================================================================================

TOP 10 GARAGE ELECTRICAL VIOLATIONS:

VIOLATION 1: Freezer Outlet Without GFCI (⚡ LA COUNTY SPECIFIC!)
❌ Problem: Garage freezer outlet installed without GFCI protection
   Why it fails: LA County amendment requires GFCI on ALL garage receptacles
   How to fix: Install GFCI outlet or GFCI breaker on freezer circuit
   Reference: 2022 CEC 210.8(A)(2) + LA County amendment
   Cost to fix: $15-30 (GFCI outlet) or $40-80 (GFCI breaker)
   
   ⚠️ CRITICAL: This is LA County-specific amendment
   California state code (2022 CEC): Allows exception for dedicated appliances
   LA County: NO exception - freezers MUST have GFCI

VIOLATION 2: No GFCI on General Garage Outlets
❌ Problem: General use garage outlets without GFCI protection
   Why it fails: Code requires GFCI on ALL garage receptacles
   How to fix: Install GFCI outlets or GFCI breaker
   Reference: 2022 CEC 210.8(A)(2)
   Cost to fix: $15-30 per outlet or $40-80 for breaker

VIOLATION 3: GFCI Not Functioning
❌ Problem: GFCI test button doesn't trip circuit
   Why it fails: Defective GFCI or wiring error
   How to fix: Replace GFCI or correct wiring
   Reference: 2022 CEC 210.8(D)
   Cost to fix: $15-50

VIOLATION 4: No Receptacle in Garage
❌ Problem: Garage has no electrical outlet at all
   Why it fails: Code requires minimum 1 receptacle
   How to fix: Install at least 1 GFCI-protected receptacle
   Reference: 2022 CEC 210.52(G)
   Cost to fix: $100-200

VIOLATION 5: No Lighting with Wall Switch
❌ Problem: Garage has no light fixture OR no wall switch
   Why it fails: Code requires lighting controlled by wall switch
   How to fix: Install light fixture + switch at entry
   Reference: 2022 CEC 210.70(A)(2)(a)
   Cost to fix: $100-250

VIOLATION 6: Wrong Wire Gauge on 20A Circuit
❌ Problem: 14 AWG wire on 20A breaker
   Why it fails: Wire too small (fire hazard)
   How to fix: Rewire with 12 AWG OR reduce breaker to 15A
   Reference: 2022 CEC 210.19
   Cost to fix: $200-500 (rewire) or $20 (reduce breaker)

VIOLATION 7: Reversed Outlet Polarity
❌ Problem: Hot and neutral wires swapped
   Why it fails: Safety hazard
   How to fix: Correct wiring at outlet
   Reference: 2022 CEC 200.11
   Cost to fix: $25-50

VIOLATION 8: Garage Door Opener Outlet Not GFCI
❌ Problem: Plug-in garage door opener receptacle without GFCI
   Why it fails: All garage receptacles need GFCI
   How to fix: Install GFCI outlet or GFCI breaker
   Reference: 2022 CEC 210.8(A)(2)
   Cost to fix: $15-80

VIOLATION 9: Exposed Romex Not Protected
❌ Problem: Romex cable exposed in garage at risk of damage
   Why it fails: Must be protected from physical damage
   How to fix: Install conduit or run through studs
   Reference: 2022 CEC 334.15
   Cost to fix: $100-300

VIOLATION 10: Missing Circuit Labels
❌ Problem: Panel doesn't identify garage circuits
   Why it fails: Code requires circuit directory
   How to fix: Create accurate labels
   Reference: 2022 CEC 408.4
   Cost to fix: $25-75

RAG QUERY EXAMPLES
================================================================================

Q: "Do I need GFCI for garage freezer in LA County?"
A: "YES. LA County requires GFCI protection on ALL garage receptacles, including 
freezers (Section 210.8(A)(2) + LA County amendment). This differs from California 
state code which allows exception for dedicated appliances. LA County has NO 
exception. Inspector WILL test freezer outlet GFCI. Install GFCI outlet ($15-30) 
or GFCI breaker at panel ($40-80)."

Q: "How many circuits do I need for garage?"
A: "Minimum: 1× 20A receptacle circuit (GFCI required) + 1× 15-20A lighting circuit. 
Recommended: 2-3 circuits for basic garage, 3-4 for workshop, 4-5 with EV charger. 
All garage receptacles must be GFCI protected. Permit required for new circuits via 
EPIC-LA: epicla.lacounty.gov"

Q: "How much does garage electrical cost?"
A: "Typical costs: GFCI upgrade only ($155-440), Basic garage 2-3 circuits 
($1,125-2,320), Workshop 4-5 circuits ($1,770-3,630), With EV charger ($2,360-5,140). 
Most common: $1,500-1,800 for standard garage. Includes permit ($100-200), materials 
($225-520), labor ($800-1,600). Get 3 quotes from licensed C-10 contractors."

Q: "Can I replace garage outlets without permit?"
A: "Yes, if replacing outlets in same locations (Section 82-3(a)). This is minor 
repair exempt from permit. However, ALL garage outlets MUST be GFCI protected (no 
exceptions in LA County). Strongly recommend upgrading to GFCI if not already present. 
If adding new circuits: Permit required."

Q: "What does inspector check for garage outlets?"
A: "Inspector verifies: (1) ALL garage receptacles GFCI protected (including freezer - 
LA County specific!), (2) GFCI test button works (will press EVERY outlet), 
(3) At least 1 receptacle present, (4) Lighting with wall switch, (5) Proper wiring 
(no reversed polarity), (6) Garage door opener circuit proper. See 
cross-reference-garage-wiring-LA.txt for complete checklist."

Q: "My garage freezer outlet failed inspection. Why?"
A: "Most common: Freezer outlet doesn't have GFCI protection. LA County REQUIRES 
GFCI on ALL garage receptacles including freezers (differs from state code). Fix: 
Install GFCI outlet ($15-30) or GFCI breaker at panel ($40-80). Test GFCI before 
requesting re-inspection through EPIC-LA."

Q: "Difference between LA County and California state code for garages?"
A: "LA COUNTY: ALL garage receptacles require GFCI (including freezers, dedicated 
appliances) - NO exceptions. CALIFORNIA STATE CODE (2022 CEC): Allows exception for 
dedicated appliance circuits like freezers. LA County amendment is MORE restrictive. 
Inspector enforces LA County requirement."

Q: "Do I need permit for garage door opener?"
A: "Depends. Plugging opener into existing GFCI outlet: NO permit. Installing new 
circuit for opener: YES permit required. Fee: $36 base + circuit fee (~$75-150 total). 
Apply via EPIC-LA: epicla.lacounty.gov. Outlet must be GFCI protected."
