DECISION TREE: AFCI vs. GFCI Breakers

┌────────────────────────────────────────────────────────┐
│ Which breaker type do I need?                          │
├────────────────────────────────────────────────────────┤
│                                                         │
│ STANDARD BREAKER (Basic overcurrent protection):      │
│   Use for:                                             │
│   → Lighting circuits (no AFCI/GFCI requirement)      │
│   → Appliance circuits (dedicated)                    │
│   → Older homes (not being remodeled)                 │
│   Cost: $5-20                                          │
│                                                         │
│ AFCI BREAKER (Arc Fault Circuit Interrupter):         │
│   Required for:                                        │
│   → Bedroom circuits (2022 CEC 210.12)               │
│   → Living areas (family rooms, dens)                 │
│   → Dining rooms, closets, hallways                   │
│   → Most 120V branch circuits in dwelling units       │
│   Not required for:                                    │
│   → Bathrooms, garages, outdoors (use GFCI)          │
│   → Kitchen counter circuits (use GFCI)               │
│   Cost: $40-70                                         │
│                                                         │
│ GFCI BREAKER (Ground Fault Circuit Interrupter):      │
│   Required for:                                        │
│   → Bathrooms (all receptacles)                       │
│   → Kitchens (counter receptacles)                    │
│   → Garages (all receptacles)                         │
│   → Outdoors (all receptacles)                        │
│   → Crawlspaces, basements                            │
│   → Laundry areas                                      │
│   → Pools/spas                                         │
│   Cost: $40-80                                         │
│                                                         │
│ DUAL-FUNCTION BREAKER (AFCI + GFCI combined):         │
│   Required for:                                        │
│   → Newer code: Bedroom circuits near water           │
│   → Kitchen circuits if AFCI also required            │
│   → Combination protection situations                  │
│   Cost: $60-100                                        │
│                                                         │
│ WHEN REPLACING BREAKERS:                               │
│   → Must match existing if same type/size              │
│   → If adding AFCI/GFCI: Check compatibility with panel
│   → Not all panels accept AFCI/GFCI breakers          │
│   → May need panel upgrade if incompatible            │
│                                                         │

PRACTICAL GUIDE: Panel & Breaker Installation
================================================================================

STEP-BY-STEP PANEL WORK:

PHASE 1: ASSESSMENT & PLANNING

1. Evaluate Current Panel
   Check for:
   □ Available breaker spaces (empty slots)
   □ Panel rating (100A, 200A, etc.)
   □ Panel age (older than 20 years may need replacement)
   □ Panel brand/type (some brands recalled - FPE, Zinsco)
   □ Bus bar rating (determines max total breaker amperage)
   □ Working clearances (36" width, 30" depth, 6.5' height minimum)
   □ Accessibility (not in bathroom, closet, behind obstacles)
   □ Signs of damage (rust, burn marks, loose connections)

2. Calculate Load Requirements
   Total connected load:
   □ Add up all existing circuits (amperage)
   □ Add planned new circuits
   □ Apply demand factors (not all circuits at max simultaneously)
   □ Verify total doesn't exceed service capacity
   
   Example calculation:
   - Existing circuits: 15 circuits × 15A = 225A nameplate
   - Apply 40% demand factor: 225A × 0.4 = 90A actual demand
   - Service capacity: 200A
   - Remaining capacity: 200A - 90A = 110A available
   - Can add more circuits if needed

3. Determine Panel Needs
   Decision factors:
   
   Panel full (no empty spaces)?
   → Option 1: Replace with larger panel (more spaces)
   → Option 2: Add sub-panel (additional spaces)
   → Option 3: Tandem breakers if panel allows (2 circuits in 1 space)
   
   Panel damaged or old?
   → Replace entire panel
   → Consider service upgrade at same time
   
   Need AFCI/GFCI breakers?
   → Check if existing panel compatible
   → May need panel replacement if incompatible

4. Check for Recalled Panels
   Dangerous panel brands (REPLACE immediately):
   ❌ Federal Pacific Electric (FPE) - Fire hazard
   ❌ Zinsco / Sylvania - Failure to trip
   ❌ Challenger (some models) - Overheating
   
   If you have these brands:
   → Recommend immediate replacement
   → Safety issue (breakers may not trip on overload)
   → Insurance may require replacement
   → Cost: $1,500-3,000 for replacement

5. Plan for Clearances
   Required working space (2022 CEC 110.26):
   - Width: 36" minimum (or width of panel, whichever greater)
   - Depth: 30" minimum (clear space in front)
   - Height: 6.5 feet minimum (6 feet 6 inches)
   - No storage in clearance area
   - No doors swinging into space
   - Good lighting required
   
   Accessibility requirements:
   - Cannot be in bathroom
   - Cannot be in clothes closet (with hanging space)
   - Cannot be behind locked door (unless emergency personnel have key)
   - Must be readily accessible

PHASE 2: PERMIT APPLICATION (For Panel Replacement/Sub-Panel)

1. Determine if Permit Needed
   Permit REQUIRED for:
   ✓ Panel replacement (even if same size)
   ✓ Sub-panel installation
   ✓ Panel relocation
   ✓ Service upgrade with new panel
   ✓ Adding new circuits/breakers
   
   Permit NOT REQUIRED for:
   ✗ Replacing single breaker (same type/size) per Section 82-3(g)
   ✗ Resetting tripped breaker
   ✗ Labeling circuits

2. Apply via EPIC-LA
   URL: epicla.lacounty.gov
   Permit type: "Electrical Permit - Panel Replacement" or "Sub-Panel Installation"
   
   Application details:
   □ Current panel rating (100A, 200A)
   □ New panel rating
   □ Service upgrade (if applicable)
   □ Number of circuits to transfer
   □ Sub-panel location (if applicable)
   □ Feeder size (if sub-panel)
   □ Work description
   □ Contractor license # (C-10 required)

3. Pay Permit Fee
   Fee structure:
   - Base: $36.00
   - Panel work: ~$100-300 (varies by scope)
   - Service upgrade: Additional $100-200
   - Typical total: $150-500
   - Verify current: (626) 458-3180

4. Wait for Approval
   Timeline:
   - Simple panel replacement: 5-10 days
   - With service upgrade: 10-15 days
   - May require load calculations

PHASE 3: INSTALLATION (Licensed Electrician)

Main Panel Replacement Steps:

Safety First:
⚠️ CRITICAL: Utility must disconnect power at meter
- Cannot safely replace main panel with power on
- Schedule utility disconnection
- Work performed while house without power
- Reconnection after inspection passes

1. Power Disconnection
   □ Schedule utility to disconnect at meter
   □ Verify power off (test with voltage meter)
   □ Lock out / tag out meter
   □ Proceed with replacement

2. Remove Old Panel
   □ Label all circuits (photograph before disconnecting)
   □ Disconnect all branch circuits
   □ Disconnect service entrance conductors
   □ Disconnect grounding/bonding
   □ Remove old panel from wall
   □ Patch wall if necessary

3. Install New Panel
   □ Mount new panel enclosure securely
   □ Verify level installation
   □ Maintain proper height (center at 5-6 feet typical)
   □ Ensure working clearances
   □ Secure to wall studs or solid backing

4. Connect Service Entrance
   □ Route service entrance conductors into panel
   □ Connect to main breaker lugs (top typically)
   □ Verify proper torque on connections
   □ Install main bonding jumper (neutral-ground bond)
   □ Only at main panel (not sub-panels)

5. Connect Grounding System
   □ Connect grounding electrode conductor
   □ Bond to neutral bus bar (main panel only)
   □ Verify ground rods present (2 minimum)
   □ Bond water pipe if metal plumbing
   □ All metal enclosures bonded

6. Install Branch Circuit Breakers
   □ Snap breakers into bus bars
   □ Connect branch circuit wires
   □ Organize wires neatly
   □ Verify no conductor touching enclosure
   □ Torque all connections properly
   □ Install AFCI/GFCI breakers where required

7. Label All Circuits
   □ Create accurate circuit directory
   □ Label what each breaker controls
   □ Use printed labels (not handwritten)
   □ Place directory inside panel cover
   □ Mark panel rating on cover

8. Final Checks Before Energizing
   □ All connections tight
   □ No loose wires
   □ No conductors touching enclosure
   □ Ground and neutral properly separated (if sub-panel)
   □ Cover installed
   □ Working clearances maintained
   □ Labeling complete

Sub-Panel Installation Steps:

1. Determine Feeder Size
   Calculate based on loads:
   - 60A sub-panel: 6 AWG copper or 4 AWG aluminum
   - 100A sub-panel: 2 AWG copper or 1/0 AWG aluminum
   - 125A sub-panel: 1 AWG copper or 2/0 AWG aluminum
   
   Reference: 2022 CEC Table 310.12

2. Install Feeder Circuit
   □ Install breaker in main panel (feeder breaker)
   □ Run feeder conductors to sub-panel location
   □ Proper wire sizing for amperage and distance
   □ 4-wire feeder required (hot, hot, neutral, ground)
   □ Conduit if exposed
   □ Proper support every 4.5 feet

3. Install Sub-Panel
   □ Mount sub-panel enclosure
   □ Connect feeder conductors
   □ DO NOT bond neutral-ground in sub-panel
   □ Separate neutral and ground bus bars
   □ Connect ground to ground bar only
   □ Connect neutral to neutral bar only

4. Grounding at Sub-Panel
   Critical differences from main panel:
   ❌ NO neutral-ground bond in sub-panel
   ❌ Neutral and ground must be separate
   ✓ Ground bar connected to feeder ground wire only
   ✓ Neutral bar connected to feeder neutral wire only
   
   For detached structures:
   ✓ Separate grounding electrode system (ground rods)
   ✓ Bond ground rods to sub-panel ground bar
   ✓ Still NO neutral-ground bond at sub-panel

5. Install Branch Circuits in Sub-Panel
   □ Install breakers as needed
   □ Connect branch circuits
   □ Label all circuits
   □ Maintain proper organization

Replacing Single Breaker (No Permit):

1. Turn Off Main Breaker
   □ Shut off main breaker (de-energizes panel)
   □ Or coordinate utility disconnection if needed
   □ Verify power off with voltage tester

2. Remove Old Breaker
   □ Loosen terminal screw
   □ Disconnect wire from breaker
   □ Release breaker from bus bar (may require pushing/pulling)
   □ Remove breaker

3. Install New Breaker
   □ Verify correct amperage rating (same as old)
   □ Verify correct type (standard, AFCI, GFCI)
   □ Verify compatible with panel brand
   □ Snap onto bus bar
   □ Connect wire to terminal
   □ Torque to specification

4. Restore Power & Test
   □ Turn on main breaker
   □ Turn on new breaker
   □ Test circuit functionality
   □ Test AFCI/GFCI test button (if applicable)

PHASE 4: INSPECTION

Final Inspection (Panel Work):

Inspector verifies:
□ Panel properly rated for service (100A, 200A match)
□ Panel securely mounted
□ Proper working clearances (36" × 30" × 6.5')
□ Panel location accessible (not in bathroom/closet)
□ All breakers properly installed
□ Correct breaker sizes for circuits (match wire gauge)
□ No double-tapping (one wire per terminal unless rated)
□ AFCI breakers installed where required (bedrooms)
□ GFCI breakers installed where required (bathrooms, kitchens, etc.)
□ Main bonding jumper present (neutral-ground bond at main panel only)
□ Grounding electrode conductor properly sized and connected
□ All connections tight and torqued
□ No exposed conductors
□ Circuit directory complete and accurate
□ Panel labeled with amperage rating
□ Cover installed with proper clearances

Sub-Panel Specific Checks:
□ Feeder wire sized correctly
□ Feeder breaker sized correctly (at main panel)
□ NO neutral-ground bond in sub-panel
□ Neutral and ground bars separate
□ Grounding electrode system (if detached structure)
□ 4-wire feeder present (not 3-wire)

Testing by inspector:
- Verify breaker trips when test button pressed (AFCI/GFCI)
- Check torque on main connections (may use torque screwdriver)
- Verify proper voltage (120V/240V)
- Test ground continuity

If inspection PASSES:
✓ Work approved
✓ Utility can reconnect power (if disconnected)
✓ Certificate issued

If inspection FAILS:
✗ Violations noted
✗ Fix issues
✗ Re-inspection required
✗ Power stays off until approved

INSPECTOR CHECKLIST: Panels & Breakers
================================================================================

WHAT INSPECTOR WILL VERIFY:

PANEL RATING & SIZING:
□ Panel rating matches service (100A panel on 100A service)
□ Main breaker matches service (200A main on 200A service)
□ Adequate circuit spaces for all circuits
□ No overloaded bus bars
□ Panel brand/type acceptable (not recalled models)

PANEL LOCATION & CLEARANCES:
□ Working space: 36" width minimum
□ Working space: 30" depth minimum
□ Working space: 6.5 feet height minimum
□ No storage in working space
□ Not in bathroom
□ Not in clothes closet (with hanging space)
□ Readily accessible
□ Proper lighting

PANEL INSTALLATION:
□ Securely mounted to wall
□ Level installation
□ Proper height (center 5-6 feet typical)
□ All knockouts closed or filled
□ Cover installed properly
□ No gaps in enclosure

BREAKERS:
□ All breakers properly seated on bus bars
□ Correct amperage ratings (match wire gauge)
□ No double-tapping (unless rated for it)
□ AFCI breakers in bedrooms and living areas
□ GFCI breakers in bathrooms, kitchens, garages, outdoors
□ All breakers functioning (test AFCI/GFCI)
□ Breakers compatible with panel brand

WIRING:
□ All conductors properly sized for breakers
□ All connections tight and torqued
□ No damaged insulation
□ Proper wire management (neat, organized)
□ No conductors touching panel enclosure
□ Proper wire fill (not overcrowded)
□ Color coding correct (black/red hot, white neutral, green/bare ground)

GROUNDING & BONDING:
□ Main bonding jumper present (main panel only)
□ Grounding electrode conductor present and sized correctly
□ Connected to ground rods (2 minimum)
□ Metal water pipe bonded (if present)
□ All metal enclosures bonded
□ Sub-panel: NO neutral-ground bond
□ Sub-panel: Neutral and ground bars separate

LABELING:
□ Circuit directory complete and accurate
□ Panel labeled with amperage rating
□ Warnings/cautions as required
□ AFCI/GFCI breakers labeled

COMMON INSPECTOR FINDINGS (Violations):

❌ VIOLATION 1: Double-Tapped Breakers
   Problem: Two wires connected to single breaker terminal
   Why it fails: Loose connection risk (unless breaker rated for 2 wires)
   Fix: Install separate breaker for each circuit OR use rated breaker
   Reference: 2022 CEC 110.14
   Cost to fix: $50-150 (additional breaker + labor)

❌ VIOLATION 2: Inadequate Working Clearance
   Problem: Storage or obstructions in front of panel
   Why it fails: Safety requirement (must access panel quickly)
   Fix: Remove obstructions, maintain 36" × 30" × 6.5' clearance
   Reference: 2022 CEC 110.26
   Cost to fix: $0-500 (move items or relocate panel)

❌ VIOLATION 3: Missing Circuit Directory
   Problem: No labels showing what each breaker controls
   Why it fails: Required for safety and maintenance
   Fix: Create accurate circuit directory
   Reference: 2022 CEC 408.4
   Cost to fix: $50-100 (circuit identification + labeling)

❌ VIOLATION 4: Neutral-Ground Bond at Sub-Panel
   Problem: Neutral and ground bonded together in sub-panel
   Why it fails: Creates parallel neutral path (safety hazard)
   Fix: Remove neutral-ground bond from sub-panel
   Reference: 2022 CEC 250.142
   Cost to fix: $50-150

❌ VIOLATION 5: Wrong Breaker Size for Wire Gauge
   Problem: 20A breaker on 14 AWG wire (should be 15A max)
   Why it fails: Wire overload/fire hazard
   Fix: Replace with correct breaker size OR rewire with heavier gauge
   Reference: 2022 CEC 240.4(D)
   Cost to fix: $20-50 (breaker) or $200-500 (rewire)

❌ VIOLATION 6: Missing AFCI Breakers
   Problem: Bedroom circuits without AFCI protection
   Why it fails: Code requires AFCI for bedrooms and living areas
   Fix: Install AFCI breakers on required circuits
   Reference: 2022 CEC 210.12
   Cost to fix: $40-70 per AFCI breaker

❌ VIOLATION 7: Panel in Clothes Closet
   Problem: Panel installed in closet with hanging clothes space
   Why it fails: Not permitted location
   Fix: Relocate panel OR convert to electrical equipment room
   Reference: 2022 CEC 240.24(D)
   Cost to fix: $1,500-4,000 (major relocation)

❌ VIOLATION 8: Incompatible Breakers
   Problem: Wrong brand breakers in panel (e.g., Square D breaker in GE panel)
   Why it fails: Safety issue, breakers may not function properly
   Fix: Replace with manufacturer-approved breakers
   Reference: 2022 CEC 110.3(B)
   Cost to fix: $50-200 (correct breakers)

❌ VIOLATION 9: Oversized Main Breaker
   Problem: 200A main breaker on 100A service
   Why it fails: Main breaker must match service rating
   Fix: Replace with correct main breaker size
   Reference: 2022 CEC 408.36
   Cost to fix: $100-300

❌ VIOLATION 10: Missing Grounding Electrode Conductor
   Problem: No ground wire from panel to ground rods
   Why it fails: No path to earth ground (safety hazard)
   Fix: Install grounding electrode conductor to ground rods
   Reference: 2022 CEC 250.64
   Cost to fix: $200-500

PERMIT DECISION TREE:

Panel/breaker work:
  │
  ├─ Replacing entire panel?
  │  └─ YES → PERMIT REQUIRED (always)
  │     Fee: $36 base + panel work (~$150-400 total)
  │     Process: EPIC-LA (epicla.lacounty.gov)
  │     Applicant: Licensed C-10 contractor
  │     Inspection: Final inspection required
  │
  ├─ Installing sub-panel?
  │  └─ YES → PERMIT REQUIRED
  │     Fee: $36 base + sub-panel fees (~$150-300)
  │     Process: EPIC-LA
  │
  ├─ Relocating panel?
  │  └─ YES → PERMIT REQUIRED
  │     Fee: $36 base + relocation fees (~$200-500)
  │     Major work, complex
  │
  ├─ Adding new circuit/breaker?
  │  └─ YES → PERMIT REQUIRED
  │     Fee: $36 base + per-circuit fee (~$75-150)
  │     Part of circuit installation permit
  │
  ├─ Replacing single breaker (same type/size)?
  │  └─ NO PERMIT (minor repair per Section 82-3(g))
  │     Must be same amperage and type
  │     No electrical service interruption
  │
  └─ Upgrading breakers to AFCI/GFCI (no new circuits)?
     └─ Technically NO permit required
        But recommended to document for safety/value
        Some contractors pull permit anyway

  - Verify current: (626) 458-3180

COMMON VIOLATIONS: Panels & Breakers
================================================================================

TOP 10 PANEL/BREAKER VIOLATIONS:

VIOLATION 1: Double-Tapped Breakers
❌ Problem: Two wires on one breaker terminal
   Why it fails: Loose connection fire risk
   How to fix: Separate breaker for each OR rated breaker
   Reference: 2022 CEC 110.14
   Cost to fix: $50-150

VIOLATION 2: Inadequate Working Clearance
❌ Problem: Panel blocked by storage
   Why it fails: Safety access requirement
   How to fix: Clear 36" × 30" × 6.5' space
   Reference: 2022 CEC 110.26
   Cost to fix: $0-500

VIOLATION 3: Missing Circuit Directory
❌ Problem: No circuit labels
   Why it fails: Required for safety
   How to fix: Label all circuits
   Reference: 2022 CEC 408.4
   Cost to fix: $50-100

VIOLATION 4: Neutral-Ground Bond at Sub-Panel
❌ Problem: Bonded at sub-panel
   Why it fails: Parallel neutral path
   How to fix: Remove bond
   Reference: 2022 CEC 250.142
   Cost to fix: $50-150

VIOLATION 5: Wrong Breaker Size
❌ Problem: 20A breaker on 14 AWG wire
   Why it fails: Fire hazard
   How to fix: Correct breaker size
   Reference: 2022 CEC 240.4(D)
   Cost to fix: $20-500

VIOLATION 6: Missing AFCI Breakers
❌ Problem: No AFCI on bedrooms
   Why it fails: Code requirement
   How to fix: Install AFCI breakers
   Reference: 2022 CEC 210.12
   Cost to fix: $40-70 each

VIOLATION 7: Panel in Closet
❌ Problem: Panel in clothes closet
   Why it fails: Not permitted
   How to fix: Relocate panel
   Reference: 2022 CEC 240.24(D)
   Cost to fix: $1,500-4,000

VIOLATION 8: Incompatible Breakers
❌ Problem: Wrong brand breakers
   Why it fails: Safety issue
   How to fix: Use correct brand
   Reference: 2022 CEC 110.3(B)
   Cost to fix: $50-200

VIOLATION 9: Oversized Main Breaker
❌ Problem: Main doesn't match service
   Why it fails: Must match rating
   How to fix: Correct main breaker
   Reference: 2022 CEC 408.36
   Cost to fix: $100-300

VIOLATION 10: Missing Ground Connection
❌ Problem: No ground electrode conductor
   Why it fails: No earth ground
   How to fix: Install ground wire
   Reference: 2022 CEC 250.64
   Cost to fix: $200-500

RAG QUERY EXAMPLES
================================================================================

Q: "How much does panel replacement cost?"
A: "Panel replacement only (same service): $1,850-4,100, typical $2,500-3,000. 
With service upgrade (100A→200A): $4,250-8,500, typical $5,500-7,000. Sub-panel 
installation: $1,310-2,670, typical $1,800-2,200. Includes permit ($150-500), 
materials, labor, utility coordination. Get 3 quotes from licensed C-10 contractors."

Q: "Do I need permit to replace breaker?"
A: "Depends. Replacing single breaker (same type/size): NO permit (Section 82-3(g)). 
Panel replacement: YES permit required. Sub-panel: YES permit. Adding new circuit: 
YES permit. Fee: $36 base + work fees = $150-500 total. Apply via EPIC-LA: 
epicla.lacounty.gov"

Q: "What's difference between AFCI and GFCI breaker?"
A: "AFCI (Arc Fault): Detects arc faults, required for bedrooms/living areas. 
Cost: $40-70. GFCI (Ground Fault): Detects ground faults, required for bathrooms/ 
kitchens/garages/outdoors. Cost: $40-80. Dual-function (both): $60-100. Reference: 
2022 CEC 210.8 (GFCI), 210.12 (AFCI)."

Q: "Can I add sub-panel instead of replacing main panel?"
A: "Yes, if main panel has capacity. Sub-panel provides additional breaker slots 
without replacing main. Cost: $1,310-2,670 vs. $1,850-4,100 for main panel. 
Requirements: Feeder circuit from main, proper sizing, NO neutral-ground bond at 
sub-panel. Permit required. See cross-reference-panel-breakers-LA.txt"

Q: "What does inspector check for electrical panel?"
A: "Inspector verifies: (1) Proper panel rating for service, (2) Working clearances 
(36" × 30" × 6.5'), (3) All breakers correct size, (4) No double-tapping, 
(5) AFCI breakers on bedrooms, (6) GFCI breakers where required, (7) Main bonding 
jumper (main panel only), (8) Complete circuit directory, (9) All connections tight, 
(10) Panel not in bathroom/closet."

Q: "Why did my panel fail inspection?"
A: "Top 3 failures: (1) Double-tapped breakers (2 wires on 1 terminal - fix: separate 
breakers $50-150), (2) Missing circuit directory (fix: label circuits $50-100), 
(3) Wrong breaker sizes (fix: correct breakers $20-500). Get inspector's report, 
fix violations, request re-inspection through EPIC-LA."

Q: "Is my Federal Pacific panel dangerous?"
A: "YES. Federal Pacific Electric (FPE) panels recalled - breakers may not trip on 
overload (fire hazard). Recommend immediate replacement. Also dangerous: Zinsco, 
some Challenger models. Cost to replace: $1,500-3,000. Insurance may require/cover 
replacement. Contact licensed contractor."

Q: "What size panel do I need?"
A: "By service: 100A service = 100A panel, 200A service = 200A panel. By circuits: 
Small home (20-30 spaces), Average (30-40 spaces), Large (40-60 spaces). Most common: 
200A / 40-space panel. Sub-panels: 60A (12-space garage), 100A (20-space addition). 
Panel must match service rating."
